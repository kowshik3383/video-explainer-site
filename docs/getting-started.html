Getting started

From zero to a rendered video.mp4 in about ten minutes — one fork, one switch, one button.

What you need: a GitHub account, the gh CLI (or the web UI), and any coding agent that can edit a repo. No local video tooling, no ffmpeg on your machine.

1. Fork or clone the repo

gh repo fork kowshik3383/video-explainer-site --clone
cd video-explainer-site

Or click Fork on GitHub. The repo is public; everything you push is visible to Pages.

2. Enable GitHub Pages

gh api repos/OWNER/video-explainer-site/pages -X POST \
  -f "source[branch]=main" -f "source[path]=/docs"

This publishes the website and the player. Your video preview lives at https://OWNER.github.io/video-explainer-site/player.html.

3. Preview the demo render

Open the player URL — it auto-plays the 8-scene “How Photosynthesis Works” deck and sets the tab title to DONE at the end. That title flip is how the recorder knows when to stop.

4. Make your first video

Open your agent (Antigravity, Claude, Cursor — anything) and say:

Read AGENTS.md, take this content, and generate scenes.json:
<paste your notes, article, or topic here>

The agent edits only docs/scenes.json, runs npm run validate, commits, and pushes. Nothing else in the repo changes.

5. Render it

Go to Actions → Render video → Run workflow. About two minutes later the run produces a video artifact containing video.mp4 (1280×720).

gh workflow run render.yml --repo OWNER/video-explainer-site
gh run list --repo OWNER/video-explainer-site --limit 1
gh run watch <run-id> --exit-status
gh run download <run-id> --name video

6. Iterate

Watch the Pages preview, ask the agent for scene-level fixes (“make scene 4 shorter”, “swap the farm image for a drying-rack shot”), re-run the workflow, download a fresh artifact. Artifacts expire after 90 days — keep the ones you love.

Heads up: the recorded MP4 is silent by design. See FAQ → voice-over for the TTS plan, and scenes.json reference for the exact schema your agent targets.
