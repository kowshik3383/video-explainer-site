Design system

One source of truth (tokens.css), six typed scenes, and strict art direction. Extracted from the Reels reference: mint page, white frame, soft green gradient panel, editorial serif.

Typography

Fraunces — display

Variable serif, optical sizing, 560–620 weight. Headlines, quotes, the stat number.

Inter — body & labels

400–750 weight. Body copy, kickers (uppercase, 0.16em tracking), buttons, meta lines.

Shape & depth

  • Radii: frame 32px · panel 26px · card 22px · pill 999px.
  • Shadows are soft and green-tinted — never neutral gray: frame 0 40px 80px rgba(16,40,24,.28), card 0 24px 60px rgba(16,40,24,.22), pill 0 10px 28px rgba(16,40,24,.16).
  • Composition: 1280×720 stage → white frame → 16px inset → gradient panel. Copy left, imagery right.

Motion

  • Enter: panel fades 0.35s; contents stagger up 34px → 0, 90ms apart, power3.out.
  • Exit: scene fades out 0.35s. Progress bar fills linearly across the scene’s duration.

Art direction

  • Photography: Unsplash only, ?w=1280&q=80&auto=format&fit=crop. Natural light, one clear subject, no collages.
  • Card treatment: full-bleed photo inside --radius-card, soft shadow, one yellow floating badge (≤ 3 words).
  • One accent per scene — a yellow badge, or green checks, or an emerald quote mark. Never stacked.

Do / Don’t

  • Do keep one idea per scene — a viewer should get it in two seconds.
  • Do use values from tokens.css; if you need a new one, add it there, not inline.
  • Don’t hardcode hex values or pixel sizes in scenes.
  • Don’t change player/index/style files for a content-only update — scenes.json is the contract.
  • Don’t use more than one image per scene, or any non-Unsplash hotlink you don’t control.
