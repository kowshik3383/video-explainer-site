How it works

Full guide →
01

Paste your content

Notes, an article, a topic — anything an agent can read. No timeline, no keyframes, no editor.

02

Agent writes scenes.json

Six typed scenes, validated against a JSON schema. The agent can’t break the design because it never touches the code.

03

Click “Run workflow”

GitHub spins up Ubuntu, Playwright records the player, ffmpeg emits video.mp4. Download the artifact. Done.

Design system →

Typed scene system

title, content, stat, bullets, quote, outro. The agent picks a type; the player knows how to render it.

Reels design tokens

Mint gradient, Fraunces serif, butter-yellow badges, emerald checks — every value traces to tokens.css.

Validated before render

ajv checks scenes.json against the schema in CI. Broken content fails fast — no wasted minute of video.

One repo, whole pipeline

Player, agent contract, validator, recorder, workflow — everything lives in one public repo.

Works with any agent

Antigravity (agy), Claude, Cursor, Copilot. AGENTS.md is the contract — point any of them at it.

Silent today, voice tomorrow

Narration is written per scene now — record with speechSynthesis or merge TTS audio via ffmpeg later, no redesign.
