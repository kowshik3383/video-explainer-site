Scenes reference

docs/scenes.json is the only file your agent edits. Every scene has a type and a duration; the rest depends on the type.

Top level

FieldTypeRules
titlestringRequired. Used for the tab title while rendering.
brandstringOptional. Watermark wordmark, max 24 chars. Default REELERS.
scenesarrayRequired. 1–12 scenes, ordered intro → conclusion.

Common scene fields

FieldTypeRules
typeenumRequired. One of title, content, stat, bullets, quote, outro.
durationintegerRequired. 4–10 seconds.
kickerstringOptional. Category label, ≤ 48 chars. Rendered as uppercase with a rule.
narrationstringOptional now, required later. 1–3 spoken sentences, ≤ 600 chars. Silent today; TTS-ready.

Scene types

title — the intro

headingRequired. ≤ 72 chars. Rendered at 108px Fraunces.
textOptional one-liner under the hairline.
{ "type": "title", "kicker": "Science Explained", "heading": "How Photosynthesis Works", "text": "Sunlight in. Food and oxygen out.", "duration": 6 }

content — the workhorse split

headingRequired. ≤ 72 chars.
textRequired. ≤ 140 chars (aim ≤ 15 words).
imageOptional. Full URL, https://. Unsplash with ?w=1280&q=80&auto=format&fit=crop.
badgeOptional. ≤ 30 chars. Yellow floating pill overlapping the image.
{ "type": "content", "kicker": "The Setup", "heading": "Three ingredients", "text": "Sunlight, water, and carbon dioxide.", "image": "https://images.unsplash.com/photo-1441974231531-c6227db76b6e?w=1280&q=80&auto=format&fit=crop", "badge": "The recipe", "duration": 6 }

stat — one hero number

statRequired. ≤ 16 chars. Rendered at 150px, e.g. 50%, 3.5×, 1900.
textRequired. What the number means. ≤ 140 chars.
sourceOptional. Uppercase meta line, ≤ 80 chars.
{ "type": "stat", "kicker": "By The Numbers", "stat": "50%", "text": "Of Earth's oxygen comes from ocean phytoplankton.", "source": "The ocean is the planet's largest forest", "duration": 7 }

bullets — checklist pills

headingRequired. ≤ 72 chars.
bulletsRequired. 2–5 items, each ≤ 64 chars (aim ≤ 6 words). Each renders as a white pill with an emerald check.
{ "type": "bullets", "kicker": "The Equation", "heading": "What happens in a leaf", "bullets": ["Sunlight splits water apart", "Carbon dioxide builds glucose", "Oxygen is released"], "duration": 7 }

quote

quoteRequired. ≤ 160 chars (aim ≤ 12 words). Italic Fraunces with an emerald quote mark.
attributionOptional. ≤ 64 chars.
{ "type": "quote", "quote": "Nearly every breath you take came from a leaf.", "attribution": "Every living thing on Earth", "duration": 6 }

outro — end card

headingOptional. The wordmark. Defaults to “Reels”.
textOptional tagline.
ctaOptional. Black pill label, ≤ 42 chars.
{ "type": "outro", "heading": "Reels", "text": "Sunlight in. Life out.", "cta": "Follow for more", "duration": 5 }

Images

  • Unsplash only — never invent photo IDs, never hotlink a page that will 404 mid-render.
  • Always ?w=1280&q=80&auto=format&fit=crop. One clear subject per scene.
  • If an image fails to load the scene still renders with copy only — but the render looks broken, so verify URLs before pushing.

Validation

npm run validate checks docs/scenes.json against scenes.schema.json (ajv, Draft 2020-12). The render workflow runs it before installing Chromium — invalid content fails the run in seconds. Field-level limits above are enforced there, not just by convention.

Full example: see docs/scenes.json in the repo — the “How Photosynthesis Works” demo is a valid 8-scene deck using all six types.
