FAQ

Short answers to the questions that come up on the first weekend with Reels.

Why is my rendered video silent?

Headless Chromium recording doesn’t capture audio, and speechSynthesis doesn’t run in headless mode. Silent is the default by design. Every scene already carries narration — when you want voice, a script generates one audio file per scene from that text and ffmpeg merges them into the final MP4. No player changes needed.

Can I add voice-over now, myself?

Yes. Generate TTS audio per scene (any provider — OpenAI, Google, ElevenLabs), save as audio/scene-01.mp3 …, then in the workflow replace the convert step with an ffmpeg filter that concatenates and muxes. Budget ~30 minutes the first time; keep narration fields in sync with the scene order.

The artifact downloaded but won’t play — is the workflow broken?

Almost never broken; it’s usually the player cached at an older commit. Pages rebuilds on every push but caches aggressively — hard-refresh the player URL (Ctrl+Shift+R) or bump a query param. If the deck itself is invalid, the CI npm run validate step fails before recording, and the run log says exactly which field is wrong.

Are hotlinked Unsplash images safe?

For reliability: mostly yes; for permanence: no. Hotlinks can die or change crop. Production-grade option: download chosen images into the repo (e.g. docs/assets/) and reference them relatively — Actions checkouts then work offline and never rot. Check each photo’s license/attribution terms if you publish commercially.

How long does a render take and what does it cost?

About 2 minutes on ubuntu-latest for an 8–12 scene deck (Playwright install dominates). Compute is billed against your Actions minutes — free tier covers hundreds of renders per month. The artifact (the MP4) expires after 90 days by default; raise retention-days in render.yml if you need longer.

Can I change the resolution or aspect ratio?

The player is 1280×720 16:9 end to end. Changing it means editing --stage-width/height in tokens.css, viewport and recordVideo.size in record.js. Doable, but do it deliberately — scene layouts are composed for 16:9.

Can the agent edit index/player files ever?

No — and you shouldn’t let it. Everything the audience sees is governed by scenes.schema.json; the schema is the API between human craft and agent content. If a constraint is wrong, change it in the schema and the docs together, then re-validate.

Where does the “DONE” title come from?

docs/player.js sets document.title = 'DONE' after the last scene (plus a 2.5s end card). record.js polls the title via Playwright — flip to anything else and the recorder waits forever and the job times out at 300s.

Can I render on every push instead of a button?

Yes — swap workflow_dispatch for push on paths docs/scenes.json. You’ll get an artifact per content commit. Most people prefer the button: it keeps Actions minutes and artifact storage predictable.
